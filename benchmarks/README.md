# Benchmarks

Maintained benchmark recipes live here with compact, versioned evidence.

- `hogenom-cpu-vs-gpu/`: matched genewise DTL-rate comparison between gpurec
  on an RTX 4090 and AleRax on 24 CPU cores.

Large empirical inputs live under the ignored `data/external/` store. Benchmark
READMEs must identify their dataset root, hardware, software versions, result
files, and plot-generation command.
