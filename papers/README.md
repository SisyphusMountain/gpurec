# Papers

This directory indexes manuscripts maintained as part of the gpurec research
record.

- `gpu-reconciliation/`: the canonical differentiable GPU reconciliation
  manuscript, including its publication-input figures and reproducibility map.
- `ghost-lineages/`: an independently versioned research project mounted here
  so its manuscript and experiments remain separate from the gpurec package.

Compiled manuscript PDFs are build or release artifacts. Figure PDFs used as
manuscript inputs are versioned together with their generators and evidence.
