# gpurec-preprocess

`gpurec-preprocess` is a Rust/PyO3 Python extension that prepares tree and CCP
data for the GPU reconciliation pipeline. It parses Newick inputs, maps gene
leaves to species, builds clade/split arrays, groups families into batches, and
constructs wave layouts used by later tensor kernels.

## Files

- `Cargo.toml`: crate manifest, Python extension configuration, and Rust
  dependency list.
- `Cargo.lock`: pinned dependency versions for reproducible crate builds.
- `src/lib.rs`: Python module entry point. Exposes `preprocess_dataset` and
  `plan_batch_layouts`, parses Newick trees, builds species/family JSON output,
  and connects batching, scheduling, and layout planning.
- `src/batch_planning.rs`: family batching strategies. Validates batch inputs
  and implements sequential, clade-first-fit, and depth-first-fit packing.
- `src/scheduler.rs`: global phased wave scheduler. Builds leaf and non-leaf
  clade evaluation waves with phase metadata and wave-size limits.
- `src/layout.rs`: wave layout builder. Converts scheduled waves into compact
  permutation, leaf, split, reduction, and family-index metadata for GPU use.
- `target/`: generated Cargo build artifacts. This directory is not source
  documentation and can be regenerated by rebuilding the crate.
