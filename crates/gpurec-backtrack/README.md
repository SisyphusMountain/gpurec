# gpurec-backtrack

`gpurec-backtrack` is a Rust/PyO3 Python extension that samples reconciliation
trees from dynamic-programming tensors. It consumes NumPy views of clade,
species, split, likelihood, and topology arrays, then performs seeded stochastic
backtracking without copying the main tensor inputs.

## Files

- `Cargo.toml`: crate manifest, Python extension configuration, and Rust
  dependency list.
- `Cargo.lock`: pinned dependency versions for reproducible crate builds.
- `src/lib.rs`: Python module entry point. Exposes
  `sample_reconciliations_torch`, defines the sampling input views, species
  topology helpers, weighted log-space sampling, and event expansion logic for
  leaf, speciation, duplication, transfer, and loss nodes.
- `target/`: generated Cargo build artifacts. This directory is not source
  documentation and can be regenerated by rebuilding the crate.
