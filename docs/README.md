# Documentation

Maintained gpurec documentation is organized by audience and purpose:

- `mathematics/`: mathematical and algorithmic references;
- `internal-reviews/`: dated code reviews retained for engineering history;
- `glossary.md`: reconciliation, tensor, derivative, and unit vocabulary;
- `input-contract.md`: species/gene naming and path-resolution rules;
- the existing Markdown documents in this directory cover architecture,
  configuration, numerical behavior, and development investigations.

The indexes will be refined as the existing Markdown documentation is
classified. LaTeX sources must build without machine-specific absolute paths.
